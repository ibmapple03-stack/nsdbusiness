# NSD Business Academy — website

Public website for NSD Business Academy Limited, Yola, Adamawa State (CAC RC 9902304).

Next.js 16 · TypeScript · Tailwind CSS 4. No database and no logins: all content lives in `src/content/`, and enquiry forms are emailed to the academy office. Student and staff portals are a separate project (starting point preserved on the `platform-stage1` branch).

```bash
npm install
npm run dev     # http://localhost:3000
```
